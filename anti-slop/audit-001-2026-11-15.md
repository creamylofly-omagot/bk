# Antislop Audit 001 (2026-11-15)

Target: E-BK SMKN 1 Kota Binjai (`index.html`, `css/styles.css`, `js/app.js`, `js/api.js`, `js/local-backend.js`)

## Findings

1. **HIGH — R-37 (Design Direction Required):** No `DESIGN.md` or formal style brief exists in the repository to define palette, typography, and `ENERGY / RHYTHM / MOTION` dials.
2. **HIGH — R-02 (Em Dashes):** Em dash characters (`—`) appear in live UI strings in `js/app.js` (lines 781, 882, 965, 978) and file header comments (`js/app.js:2`, `js/local-backend.js:2`).
3. **HIGH — R-25 (Color Contrast):** Several active UI pairings fail WCAG AA: Bootstrap `text-primary` (`#0d6efd`) on `.btn-light` (`#f8f9fa`, `4.27:1` FAIL) in `index.html:163`, `.btn-outline-warning` border (`#ffc107`) on `#ffffff` (`1.63:1` FAIL for 3:1 non-text contrast) in `index.html:211`, and `text-success` (`#198754`) inside `.bg-light` (`4.33:1` FAIL) in `js/app.js:963`.
4. **HIGH — R-39 (Continuous Motion > 5s Without Pause Control):** `.login-wrapper::before` (8s) and `.login-wrapper::after` (11s) run `infinite alternate` continuously in `css/styles.css:115,122` with no user pause control.
5. **HIGH — R-39 (Clickable `div` Instead of Native `<button>`):** The counseling stat card in `index.html:255` uses `<div class="stat-card is-clickable" role="button" tabindex="0">` instead of a native `<button type="button">`.
6. **HIGH — R-39 (Base-Layer Cursor & Disabled Affordances):** `cursor: pointer` is applied piecemeal per class rather than once on enabled native/custom controls in the base CSS layer, and `:disabled` lacks `cursor: not-allowed` (`css/styles.css`).
7. **HIGH — R-39 (Heading Hierarchy, Multiple `<h1>`s & Missing `<footer>` Landmark):** `index.html` contains six `<h1>` elements across views (lines 49, 204, 357, 477, 610, 753), stat numbers use `<h2>` under non-heading labels, `#viewOrtu` places `<h2>` before `#viewMurid`'s `<h1>`, and `#mainAppSection` has no `<footer>` landmark.
8. **HIGH — R-03 (Touch Targets Below 44px):** `.btn-sm` sets `min-height: 38px` (`css/styles.css:68`) and `.combobox-option` sets `min-height: 42px` (`css/styles.css:218`), both below the 44px minimum tap target on touch devices.
9. **HIGH — R-27 (Missing Visible Error Retry State on Login Load):** When `loadLoginAccounts()` fails (`js/app.js:281-284`), only a 3.8s toast appears and the login combobox remains empty with no persistent inline error message or Retry button.
10. **MEDIUM — R-01 (Blue-to-Cyan/Teal Gradient & Radial Orbs Without Purpose Doc):** `.login-wrapper::before` and `::after` (`css/styles.css:110-123`) use blue-to-cyan/teal gradients and radial orbs without a documented brand/hierarchy purpose in `DESIGN.md`.
11. **MEDIUM — R-09 (Eyebrow Pill Above `<h1>`):** `.school-pill` sits directly above `<h1>` on the login card (`index.html:46-49`) mimicking an AI eyebrow badge; folding the school name into the main heading/subhead removes ornament.
12. **MEDIUM — R-06 (Default Typeface & Tracked Uppercase Table Headers):** `Plus Jakarta Sans` is loaded without a written brand reason and `.table thead th` uses `text-transform: uppercase; letter-spacing: 0.03em` (`css/styles.css:354-355`).
13. **MEDIUM — R-19 (Stacked Template Entrance Animations):** All six views (`#viewGuruBK`..`#viewAdminData`), all 4 `.stat-card`s with stagger, `.login-card`, `.combobox-listbox`, and modals animate simultaneously on mount (`css/styles.css:460-530`) without a declared `MOTION` dial.
14. **MEDIUM — R-12 (Blanket Card Elevation):** Every `.stat-card` and `.content-card` carries `box-shadow: var(--shadow-sm)` (`css/styles.css:273,306`) instead of keeping ground-plane surfaces flat and elevating only active/overlay surfaces.
15. **LOW — R-11 (Overuse of Pill Border Radius):** `rounded-pill` is applied across header buttons, action buttons, status badges, and counts (`index.html:157,162,168,209,211,215,...`) alongside `rounded-3` and `rounded-4`, diluting radius hierarchy.
16. **LOW — R-05 / R-14 (Uniform 4-Card Stat Grid):** Guru BK (`index.html:223-286`) uses four visually identical stat cards of equal weight even though pending counseling/SP cases are the primary operational alerts.
17. **LOW — R-31 / `antislop-code` (Box-Drawn ALL-CAPS Banner Comments):** `css/styles.css`, `js/app.js`, `js/api.js`, and `js/local-backend.js` contain 20 decorative `/* ==== ... ==== */` and `// ==== ... ====` ALL-CAPS section banners that add noise rather than constraints.
